# Qwenagenda (PWA, GO 1)
Svelte + Vite + vite-plugin-pwa. Données locales (IndexedDB), aucune donnée dans le dépôt.
- `npm install` puis `npm run dev` pour tester, `npm run build` pour produire `dist/`.
- Publication : déposer le contenu de `dist/` sur la branche servie par GitHub Pages (déploiement manuel).
- Style : `src/tokens.css` est extrait de `style.css` [redacted] ; `src/app.css` n'utilise que ces jetons.
